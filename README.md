# Todo Demo

A small offline to-do app for Android — Kotlin, Jetpack Compose, Material 3, Room.
No login, no network permission, no analytics. All data lives on the device.

## Install the APK

`TodoDemo.apk` in this folder is a signed release build, ready to install.

```
adb install -r TodoDemo.apk
```

Or copy it to the phone and open it — Android will ask you to allow
"Install unknown apps" for whichever app you opened it from.

- Package: `com.demo.todo`
- Min Android 7.0 (API 24), target API 36
- Size: ~1.4 MB

## Features

| Screen | What it does |
|---|---|
| **Home** | Today's tasks (due today, overdue, and undated), Total / Completed / Pending counts, progress bar, `+` button |
| **Tasks** | Every task with All / Pending / Completed filters |
| **Settings** | Theme (Follow system / Light / Dark) and Clear completed tasks |

Each task row has a checkbox to complete it, a pencil to edit, and a bin to delete.
Deleting shows an Undo snackbar. Tasks have a title, an optional description, and an
optional due date.

## Build from source

Open the folder in Android Studio and hit Run, or from a terminal:

```
./gradlew assembleDebug      # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease    # app/build/outputs/apk/release/app-release.apk
```

`gradle.properties` pins `org.gradle.java.home` to the JDK bundled with Android Studio
on this machine. On another machine, delete that line and let Gradle find a JDK 17+.
`local.properties` (the SDK path) is git-ignored and regenerated by Android Studio.

Release signing uses `app/demo-keystore.jks` with the credentials in `gradle.properties`.
It is a throwaway demo key — replace it before publishing anything real.

## Layout

```
app/src/main/java/com/demo/todo/
├─ data/        Room entity, DAO, database, repository
├─ settings/    theme preference (SharedPreferences)
├─ ui/
│  ├─ theme/    Material 3 light + dark colour schemes
│  ├─ nav/      NavHost, bottom bar, FAB, undo snackbar
│  ├─ home/ tasks/ edit/ settings/   the four screens
│  └─ components/  TaskRow, EmptyState
└─ vm/          TaskViewModel, AddEditViewModel, ThemeViewModel
```

Dependencies are versioned in `gradle/libs.versions.toml`.
No DI framework — `TodoApplication` holds the repository and preferences directly.
